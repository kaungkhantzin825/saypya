### Gotchas that cost time (all documented in FRONTEND_GUIDE.md)

- **Accessors don't serialise.** Nothing declared `$appends`, so `thumbnail_url`,
  `current_price`, `image_url`, … would all have been `undefined` in Vue. Added `$appends`
  to Course/Lesson/HeroSlide/BlogPost and made the `Course` aggregates use loaded relations
  to avoid N+1.
- **Exam answer encoding.** `correct_answer` for MCQ is the option **index as a string**,
  not the option text; true/false is lowercase. An agent had built `Exams/Take.vue` with
  option *text* as radio values — fixed.
- **`request()->ajax()` is true for Inertia** (it sends `X-Requested-With`). Endpoints that
  returned JSON for AJAX callers must check `X-Inertia` first, else the JSON lands in the
  page. Fixed in `CourseController::toggleWishlist`, `WishlistController::toggle`,
  `LessonController`.
- **Layouts can't take props from the page** — Inertia renders `h(layout, {...page.props})`,
  so `title`/`subtitle` must come from the controller.
- **`courses` has no `is_published` column** — it's `status = 'published'`. Exams *do* have
  `is_published`. `EnrollmentController::store` still reads `$course->is_published` (dead
  code — routes use `CourseController::enroll`).
